**How to use it.** Start this checklist at rough-in, not at the end of the job. Each line needs a status (Done / Open / N/A), the evidence ID (photo, test record, document), the role that verified it, and the date. Write N/A with a reason instead of leaving a line blank. A blank line means the turnover package is incomplete.

A tracker version of this list is in [`turnover-commissioning-checklist.csv`](turnover-commissioning-checklist.csv).
