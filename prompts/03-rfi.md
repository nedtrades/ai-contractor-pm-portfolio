# 03. Prompt: Request for Information (RFI)

```text
Draft an RFI from a plumbing / mechanical contractor to the project's
design team.

Inputs: RFI number, site, drawing sheet and detail or spec section, field
condition notes, photo IDs, options the field team sees, what work stops if
unanswered, date the answer is needed.

Structure: title with RFI number and a one-line problem statement;
drawing/spec reference; field condition (facts only, with photo IDs);
the question (one sentence); options we see (for the design team to
decide); impact if not answered by the date; response needed by.

Rules:
- The field condition section contains only observed facts.
- Options are suggestions. Do not state that any option is code-compliant
  or approved. If an option needs design or authority approval, say so.
- Do not make up dimensions or measurements.
- List missing inputs under "GAPS FOR REVIEWER".

INPUTS:
[paste here]
```

## Human verification step

Confirm the sheet and spec references against the current drawing set revision. Remove any option the licensed reviewer would not stand behind. Run the [human verification checklist](00-human-verification-checklist.md).
