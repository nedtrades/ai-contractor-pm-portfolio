# Prompts

Reusable prompts I give an AI assistant to draft project documents and customer messages. Each one:

- starts from field facts I paste in (notes, readings, photos list, document IDs)
- tells the AI not to add facts, numbers, code references or promises that are not in the input
- tells the AI to list gaps instead of filling them
- ends with a **human verification step** the licensed reviewer completes before anything is sent

Paste the [style guide](../templates/client-correspondence-style-guide.md) into the session first, or attach it.

|---|---|---|
| 00 | [Human verification checklist](00-human-verification-checklist.md) | Used on every draft |
| 01 | [Status update](01-status-update.md) | Weekly status update per site |
| 02 | [Turnover and closeout letter](02-turnover-closeout-letter.md) | Turnover letter and package index |

Customer data rule: real job information only goes into AI tools the customer's data rules allow. Published examples, like everything in this repo, are anonymized.
