# 00. Human Verification Checklist (the review gate)

Every AI-assisted draft passes this checklist before it is sent or filed. The reviewer is the licensed professional responsible for the scope: Licensed Plumbing Manager for plumbing, Mechanical Manager for HVAC/R and hydronic. The AI can run a self-check with this list, but its self-check does not count as the review.

## Facts

- [ ] Every number (reading, quantity, time, date, cost) matches its source record. I opened the source, not my memory of it.
- [ ] Every equipment tag, model and serial matches the equipment list.
- [ ] Every document ID and revision matches the document register.
- [ ] Every statement about what someone saw is attributed to who saw it.
- [ ] Nothing in the draft came from the AI that was not in my input. If it did, it is removed or verified.

## Code, spec and safety

- [ ] Every code or spec reference is checked against the actual document in force for this site.
- [ ] No code interpretation is stated as settled unless the inspector or authority settled it.
- [ ] Any temporary condition (temporary valve, bypass, isolated system) is stated, with its safety status and the date it ends.
- [ ] Pass/fail statements are the tester's or Commissioning Agent's, against a cited spec.

## Commitments

- [ ] Every date and time we commit to is one we can meet.
- [ ] Every cost figure is from a priced quote or estimate on file.
- [ ] No promise of savings, life expectancy or performance without a cited document.
- [ ] Scope statements match the contract or approved change orders.

## Reader

- [ ] The status or answer is in sentence one.
- [ ] The ask, if any, is in the first two lines, with a time and an owner role.
- [ ] A Store Manager could act on it without calling me.
- [ ] Customer-side people are named by role.
- [ ] Style guide followed; no filler or sales language.

## Sign-off

|---|---|---|---|
| | | | |

If any box cannot be checked, the draft does not go out. Fix it, or remove the sentence.
